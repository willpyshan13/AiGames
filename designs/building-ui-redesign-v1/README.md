日期：2026-10-29。状态：**界面和紧凑岛屿已实现，运行检查通过，已提供实际截图供验收**。用户在看过四张设计稿后表示“你能按照你设计的做吗”，据此开始实现；展示原地图过宽的差异后，用户明确选择“按设计稿缩小岛屿，调整可搭建区域”。现将两侧基础岛屿缩为各3×5格，共30格，调整场景倾斜构图和岩壁厚度，同时保留五格桥梁与教学路线。

用户所说的“云台工程师”对应“云桥工程师”（CloudBridge）；“小小构建师”对应玩法菜单里的“小小建造师”（Island），当前游戏内标题为“磁力小岛”。本稿不包含“小小动物餐厅”和“自由搭建工坊”。兔子晨光背景的完整路线稿继续保留为待确认，不因本次界面设计而自动获得确认。

## 相比当前画面的主要变化

- 云桥：蓝白云海主题；整体窄导航条容纳标题、六岛进度、关卡和帮助；任务提示移到左上，避免挡住机器人和桥梁。浮岛、机器人、草地、木桥和材料图标使用一致的玩具模型质感，改善当前平板草地、粗糙侧壁及素材风格不统一的问题。
- 建造师：暖木、象牙白和草绿色主题，与云桥形成同一系列，但保留独立辨识度。界面主标题提议采用菜单现有名称“小小建造师”，小字注明“磁力小岛”。改名仅为本稿提议，尚未改动游戏字符串。
- 两款搭建模式都收起大面积编程区，保留大场景、材料选择、拆除、撤销、视角回正以及进入编程的按钮；选中材料用明确边框和勾选反馈。
- 编程模式中，16个指令槽按两行各8个排列，已选指令与可添加指令分开；运行按钮固定在右下并留足边距，避免满16条时把按钮或卡片挤出屏幕。
- 建造师编程模式将现有重复次数（1–8）、结束后前进一步、示范路线、单步、复位放入右侧执行面板。导航菜单仅收纳现有档案、保存、关卡等次级操作，不提出新玩法。

## 设计与实现边界

这是16:9横屏整体界面提案，不是运行截图。图片中机器人、星晶、桥块和目标的数量、选择状态与计数用来演示界面；未来实现必须仍由真实游戏数据驱动，不能把整张效果图铺成静态游戏或把收集物、选中状态烘焙进背景。

目前未提出关卡数量、通关条件或核心执行规则变更。材料与指令仍使用既有类型：云桥木头、草地、石头；建造师草地、木头、石头、水晶；指令放木块、前进、左转、右转、后退、跳跃、停留。两款统一为16条编排容量；实现时发现建造师的存档校验此前仅允许8条，已同步扩至16条并验证保存与读取。

初次设计未授权改变真实地图，因此首次实现保留原格子并展示了轮廓差异。用户随后已明确授权缩小岛屿及可搭建范围，现范围为x=-5…5、z=-2…2，高度不变。机器人出生点、目标、星晶位置、桥梁长度和各关示范程序保留；画面和点击射线使用同一投影。旧地图在加载时迁移，写入缩小版存档前保留原文件备份；自由搭建工坊的地图不缩小。

20:9横屏只允许在确认主体比例基础上等比适配并扩展周围背景；若需要明显改变操作位置或构图，应先补对应比例效果稿确认。帮助页、全局菜单、通关/失败反馈沿用现有逻辑；本轮未另行设计这些页面，不应默认套用尚未确认的新样式。
