## 画面要纠正什么

上一版运行画面仍有这些差异：岛体是整齐的方形厚板；岩壁是重复方块叠墙；机器人、桥梁、岛体的比例不够统一；部分装饰和机器人遮挡了地表；按钮材质较平，图标风格不一致。通过更多格子或装饰不能解决岛体轮廓问题。

第二版沿用原稿蓝白云海／暖木森林，恢复自然圆角的草地边缘、向下收窄的岩柱、统一透视与光照。岛屿底座为独立完整的形体，不再逐格复制整颗岩壁方块。游戏逻辑格、可搭桥位置、机器人与机关单独驱动；固定岛体不烘焙机器人、桥块、星晶、选中状态。

新解谜关的基础岛屿固定，只允许在标记缺口搭桥。因此既能让可行走格清楚，又能保持稿件中的完整自然岛体。已有自由搭建工坊不受此限制。

两张图为**提案效果图**，不是运行截图，也不是已实现承诺。确认后以最终图为构图与材质依据，并以本文件的格子、库存和机关规则为精确玩法依据。

## 两款游戏分别玩什么

| 游戏 | 每关的核心选择 | 主要操作 |
|---|---|---|
| 云桥工程师 | 把有限建材用在哪条路线，是否绕路拿额外星晶 | 观察地图→选路线→搭桥→试走→调整 |
| 小小建造师 | 先触发什么，再按什么顺序执行，如何用少量指令完成 | 补缺口→编排指令→逐步观察→修改→运行 |

云桥不再复制一整套编程面板，点击“试走”后机器人沿已接通的路前进；本关预算不允许同时补齐所有支路。建造师保留可视化指令，但不默认提供完整答案，不再隐式“结束后多走一步”。

## 云桥示例：风口两条路

效果图：[cloud-route-choice.png](cloud-route-choice.png)。

- 库存：木桥7、石桥1；每格花1块，只有指定缺口可放，撤销或拆除会完整退回库存。
- 近路：3个缺口，中间1格是风口。有效方案为木桥2＋石桥1，路短、不拿绕路星晶。
- 绕路：起点到中间岛4个缺口，中间岛到终点3个缺口。木桥7可连通，途中有1颗可选星晶。石桥也可用于普通缺口。
- 主目标是抵达金色终点，额外星晶不是过关前提。两条路都能通关；不能为了奖励把近路变成假选项。
- 风口放木桥时，格子显示蓝色风纹与“需要石桥”，试走停在危险格前，不直接清空作品。
- 试走中点暂停可查看机器人停在哪一格；重试保留搭桥方案。成功后显示本次路线、耗材和是否拿到额外星晶。
- 前后木桥锚点是固定场景，不计入玩家库存；图中高亮空槽才消耗建材。

初稿上方路径曾未接回终点，已定向修正；库存由4改为7，与最终绕路缺口数量一致。实现只使用本目录最终图，不使用早期生成版本。

## 建造师示例：先开门，再到家

效果图：[island-switch-program.png](island-switch-program.png)。

本关桥块库存3，图中已用3/3；指令最多8张，当前5/8。保留现有16槽布局，本关后8槽淡化锁定，不把槽位总数和当前可用容量混为一谈。

精确格子蓝图：起点(0,0)，面朝东；桥格(1,0)、(2,0)，固定地面(3,0)、(3,1)，机关(3,2)，第三座桥(4,2)，门(5,2)，目标(6,2)。其他位置为悬空，不允许越格走。

示范序列为“前进×3 → 右转 → 前进×2 → 左转 → 前进×3”。它占5张卡，执行10个基本动作；机关在第6个基本动作触发，门保持打开直到复位。按一次右转转向南，左转转回东。未开门时尝试进入门格，停止在门前并指出原因。

“重复”作用于选中的行动卡，可调整次数1–4；卡片上直接显示×N，不使用隐藏的全局重复次数。计分和容量按可见卡数计算，基本动作另设上限64，避免无限执行。循环嵌套不在本提案中。

单步会执行一个基本动作，×3卡运行时显示1/3、2/3、3/3。失败只回退刚才失败的动作，不抹掉已搭的桥和程序；“复位”恢复本次试运行起点与机关初态。提示分三级：指出相关机关→提示行动顺序→最后才展示路线。

本关只教一种新机关；多路线选择会在掌握开门规则后加入，避免同时学多个规则。

## 首批关卡节奏（提案）

| 关卡组 | 云桥工程师 | 小小建造师 |
|---|---|---|
| 1–2 | 一处断口、撤销退款；第二关出现两条都可通的路 | 前进与转向，明确面朝方向 |
| 3–4 | 建材不足以铺满所有路；第4关引入风口与石桥 | 有限桥块与指令卡容量；先规划再运行 |
| 5–6 | 一次性桥：离开后收起，改变返回路线 | 单卡重复；第6关加入机关开门 |
| 7–8 | 开关切换桥的方向，一次只连一边 | 等待与周期移动平台，无现实时间催促 |
| 9–10 | 材料箱与中继岛，需要安排取材先后 | 两个机关的先后顺序，加入可通的替代路线 |
| 11–12 | 两种已学机制组合，允许不同用材解法 | 有限卡片下的多解关，不再加新机制 |

每关只新增一个概念，前两关30–60秒，后续约1–3分钟。先做两款各3个代表关验证好玩程度，再扩展到12关，避免先铺满内容。时间是节奏目标，不是倒计时。

过关与可选挑战分开：抵达终点是基本成功，额外星晶、少用建材／指令是可选目标。只设置经验证能共同完成的挑战组合，不强迫所有人寻找唯一最优答案。没有刷资源、失败扣库存、付费提示或硬性限时。
