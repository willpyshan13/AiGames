## 动态部分

确认稿中 `2/6` 是游戏中途状态；新局从 `0/6` 开始。三轮各接送两辆列车，共六次正确到站。红车三轮目的地依次为小熊镇、松鼠林、小熊镇；蓝车回兔子村。底栏提示目的地及运行结果；每完成两次送达点亮一颗星。

点击左站/右上站安排尚未离站的火车等待或发车。J1 选择红车主线/环线；J2 选择上/下支线。火车占用岔道及车尾尚未离开时禁止切换。冲突或进错车站停止本轮，使用原有撤回按钮重新安排。全部送达后的提示仍使用原有底栏，不增加弹窗或地图。
