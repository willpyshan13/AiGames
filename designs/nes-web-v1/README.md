# NES 网页模拟器效果稿 v1

本目录仅包含界面设计稿，不是已实现的模拟器或游戏。

## 设计范围

- 网页加载 NES 游戏 ROM，由模拟器输出原版游戏画面。
- 初始状态为等待导入 `.nes` 文件；项目目前没有游戏 ROM。
- 桌面显示导入、全屏、暂停、声音与键盘提示。
- 手机横屏采用两侧触控，左侧方向键，右侧 A/B；游戏区域保持 4:3 比例，按可用高度放大，不裁掉游戏画面。
- 保留之前的单人模式偏好；具体启动自动化在选定游戏版本后验证。
- 窄屏竖屏使用同一布局转为画面在上、触控在下，显示横屏提示。
- 暂停状态覆盖半透明遮罩与“继续游戏”；载入失败时在游戏区域显示原因与重新导入入口。
- 导入游戏后隐藏中间的占位图和导入提示；上方显示文件名。静音、暂停按钮显示对应状态。

## 与现有游戏的差异

本方案展示模拟器外围界面，游戏画面与规则由导入的 ROM 决定。设计稿没有重新绘制坦克、地图或游戏素材。

## 确认范围

确认此稿后实现本地网页模拟器、ROM 导入、视频/音频输出、键盘与触屏操作、全屏和暂停；本阶段未修改游戏源码，也未接入任何 ROM。
