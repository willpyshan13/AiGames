## 方法与边界

使用桌面 Bevy 程序，默认横屏 960×540、竖屏 540×960；竖屏窗口受 macOS 可用高度限制，实际截为 1080×1676 像素。所有游戏均保存实际截图。检查器通过鼠标按压、拖动、UI 命中和滚动输入走现有操作，不直接调用游戏规则方法制造通过状态；时间按每帧 1/30 秒固定推进。多点触控另由现有摇杆测试覆盖，但本次没有安卓真机或实际手机触摸测试。

六款额外横屏为云桥、坦克、泡泡王、扫雷、经典水果机、快递员，窗口 1080×486，已读取截图确认像素为 2160×972（20:9）。首次尺寸请求曾被正常方向同步覆盖，修正检查器后重新运行；下列宽屏截图及结果均来自重新验证的实际尺寸。

规则检查与本次 UI 检查不同：坦克未手动打完八张地图，花园本次 UI 仅检查种植、开始、暂停和重置；已有规则测试覆盖八关状态衔接，不表示所有后期难度平衡均已实战验收。正常状态未提供重开按钮的游戏，不把未出现的重开按钮当作程序错误；逐款实际检查范围以下表和原始结果为准。
