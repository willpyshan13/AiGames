# 自制坦克操作修订验收

2026-10-28。用户确认要调整草地砖墙、左摇杆右开火的自制版操作手感。

## 修改

- 方向键/WASD支持长按连续移动，Space/J支持长按连发。最近按下的方向优先，松开后恢复仍按住的方向。
- 键盘与触屏使用同一移动节奏，不会同时驱动而多走一格。首次按下立即移动；转向立即调整炮口，保持0.18秒一格的步速；保留不足一帧的时间余量。
- 摇杆增加方向切换余量与进出中心死区的缓冲，减少斜向及中心附近的抖动。移动手指与开火手指分别捕获，手指轻微滑出开火按钮仍可持续射击，抬起或取消触点后停止。
- 连发统一使用玩法本身的0.28秒冷却，移除触屏单独的重复计时；过滤触摸合成的鼠标事件，避免重复捕获。
- 暂停、返回游戏库、窗口失焦或失败时清空触点捕获；恢复后旧触点不会自行继续操作。

画面布局、素材和关卡未调整，移动仍沿用原来的逐格规则。

## 验证

- `cargo test --locked --offline --lib`：196项通过，0失败。新增7项操作回归检查，覆盖长按、即时转向及恢复按键、30/60/120帧下步速一致、摇杆临界抖动、双指独立操作、滑入按钮不误开火、暂停及失焦后释放捕获。
- 桌面构建成功。
- macOS真实GPU窗口：960×540和1080×486两种逻辑尺寸各8项检查通过，覆盖键盘长按、边走边连发、松手停止、摇杆移动、开火、重开、返回游戏库及返回当前对局。截图已查看，临时截图与测试存档在验收后清理。
- 结构化结果及运行日志保留于 `output/tank-controls-check/16x9/` 与 `output/tank-controls-check/20x9/`。
- 首次20:9运行未获得窗口焦点，输入被拦截；重新启动正常获得焦点后完成上述检查。双指触摸由Bevy输入事件回归检查覆盖，未在安卓设备上验证。

检查器同时补齐WASD/J的释放处理；自制版通过开发入口运行，从游戏库回到当前对局的操作仍实际检查。游戏库中的坦克卡片按既有要求打开Yikm网页，不将该网页入口误当作自制版重新选卡检查。
