## 后续修复：放大窗口切回旧山水风格

用户反馈电脑窗口仍会出现旧画面。原因是 `snake_ui` 仅在compact布局下使用像素界面，宽窗口仍调用旧桌面山水渲染。现删除旧渲染函数、专用方向键函数及旧美术运行时引用，不再按窗口类型更换风格。宽窗口保留同一个竖向像素画布并居中；竖屏原布局保留。

新增同一个真实GPU窗口的连续尺寸切换检查，要求各阶段均存在像素棋盘节点、棋盘比例正确、开始/暂停/重开/游戏库/四向按钮完整显示。13项界面与操作检查通过，项目189项测试通过。实际图片：

- [宽窗口](../output/snake-theme-regression/wide.png)：2560×1600像素。
- [近方窗口](../output/snake-theme-regression/square.png)：1800×1666像素；macOS可用高度限制了目标900×900逻辑窗口的高度。
- [返回竖屏](../output/snake-theme-regression/portrait-return.png)：1080×1666像素。

结构化结果：`output/snake-theme-regression/result.json`。用户已确认问题发生于电脑游戏窗口。本次没有APK打包。
